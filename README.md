# PSort+

Automatically sort your party list in Final Fantasy XIV using rules based on zone, your job, and party composition. The plugin uses the game’s built-in `/psort` and is entirely client-sided.

## Features

- **Rule-based sorting** — Define when a sort runs by:
  - **Zone** — Only in selected territories/instances (e.g. specific dungeons or areas).
  - **Your job** — Only when you’re on selected jobs.
  - **Party jobs** — Only when the party contains selected jobs (e.g. “has a healer”).
- **Presets** — Save different job orders (e.g. tanks first, healers second) and pick one per rule.
- **Multiple rules** — Rules are evaluated in order; the first matching rule runs and the rest are skipped.
- **Optional conditions** — You can narrow rules with “not” conditions (e.g. “not in these zones” or “not when this job is in party”) when enabled in settings.
- **Manual sort** — Use `/psp` in chat to trigger a sort anytime (or open the config with `/psp ui` or `/psp config`).
- **In-game config** — Configure rules, presets, and options from the plugin’s window (tutorial, rules, and presets tabs).
